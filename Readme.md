# 📖 Panduan Membuka & Melihat Diagram Mermaid (.mmd)

Halo! File-file yang ada di folder ini (dengan ekstensi `.mmd`) adalah diagram **Mermaid**. Diagram ini ditulis menggunakan kode, tapi bisa dirender menjadi gambar diagram visual yang sangat rapi.

Untuk melihat bentuk asli dari diagram-diagram ini di laptop kamu, ikuti langkah-langkah simpel di bawah ini ya!

---

## 🛠️ Langkah 1: Persiapan (Install VS Code)

Cara paling mudah dan direkomendasikan untuk melihat diagram ini adalah menggunakan **Visual Studio Code (VS Code)**.
1. Jika kamu belum punya VS Code, silakan download dan install dari situs resminya: [Download VS Code](https://code.visualstudio.com/)
2. Install aplikasinya seperti biasa (tinggal klik *Next* sampai selesai).

---

## 🧩 Langkah 2: Install Ekstensi Mermaid

Setelah VS Code terinstall, kamu perlu memasang ekstensi supaya VS Code bisa menerjemahkan kode menjadi gambar diagram.

1. Buka aplikasi **Visual Studio Code**.
2. Klik ikon **Extensions** di panel sebelah kiri (atau tekan tombol `Ctrl + Shift + X`).
3. Di kolom pencarian (*Search Extensions in Marketplace*), ketik: **Mermaid Preview**.
4. Cari ekstensi bernama **"Mermaid Preview"** (biasanya yang ikonnya gurita/mermaid atau dibuat oleh *vstirbu*) atau ekstensi **"Mermaid Markdown Syntax Highlighting"**.
5. Klik tombol **Install**.

---

## 🚀 Langkah 3: Cara Membuka & Melihat Diagram

Sekarang laptop kamu sudah siap untuk membuka diagramnya!

1. **Buka Folder:** Di VS Code, klik menu `File` > `Open Folder...` dan pilih folder tempat file `.mmd` ini disimpan.
2. **Buka File:** Di panel *Explorer* (sebelah kiri), klik salah satu file diagram (misalnya `scrum_medtode.mmd`). Kamu akan melihat kodenya di layar utama.
3. **Lihat Visualnya (Preview):** 
   - Klik kanan di mana saja pada area kode tersebut.
   - Pilih menu **"Preview Mermaid"** atau **"Mermaid: Preview"**.
   - *(Alternatif)*: Kamu juga bisa menekan tombol pintas `Ctrl + Shift + V` atau mencari ikon preview kecil (seperti kaca pembesar/layar belah) di pojok kanan atas.
4. Voila! Gambar diagramnya akan muncul secara otomatis di sebelah kode. Jika kodenya kamu ubah, gambarnya akan otomatis ter-update secara *real-time*.

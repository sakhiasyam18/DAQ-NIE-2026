APLIKASI

Pusat sistem — menyimpan data instalasi Ritun di perangkat pengguna.

  • PK id — ID unik
  • app_name — Nama aplikasi
  • app_version — Versi (1.0.0)
  • installed_at — Waktu instalasi
🔒

LOCKED_APPS

Daftar aplikasi target yang bisa dikunci: Instagram, TikTok, Game.

  • PK id — ID unik
  • app_name — Nama aplikasi target
  • UK package_name — Package Android
  • category — social_media / game
  • is_active — Status aktif
⚙️

USER_LOCKED_APPS

Konfigurasi kunci per aplikasi — menghubungkan APLIKASI dengan LOCKED_APPS.

  • PK id — ID unik
  • FK aplikasi_id → APLIKASI
  • FK locked_app_id → LOCKED_APPS
  • is_locked — Status kunci aktif/nonaktif
📖

QURAN_SURAH

Data surat Al-Qur'an Juz 30 (Juz 'Amma) — 37 surat dari An-Naba hingga An-Nas.

  • PK id — ID unik
  • UK surah_number — Nomor 78–114
  • name — Nama surat latin
  • juz_number — Nomor juz (30)
🕌

QURAN_AYAT

Data ayat Al-Qur'an per surat — teks Arab untuk ditampilkan & dievaluasi.

  • PK id — ID unik
  • FK surah_id → QURAN_SURAH
  • ayat_number — Nomor ayat
  • text_arabic — Teks aksara Arab
🎙️

RECITATION_SUBMISSIONS

Setoran murajaah — rekaman suara pengguna yang ditranskripsi oleh Whisper AI.

  • PK id — ID unik
  • FK aplikasi_id → APLIKASI
  • FK ayat_id → QURAN_AYAT
  • audio_path — Path file audio
  • transcript — Hasil Whisper
  • status — pending / correct / incorrect
✅

RECITATION_EVALUATIONS

Hasil evaluasi dari Quran Recitation Checker — WER/CER scoring.

  • PK id — ID unik
  • FK submission_id → SUBMISSIONS
  • wer_score — Word Error Rate
  • cer_score — Character Error Rate
  • result — passed / failed
📊

USER_PROGRESS

Statistik & gamifikasi — streak, XP, total setoran berhasil.

  • PK id — ID unik
  • FK aplikasi_id → APLIKASI
  • total_successful_submissions
  • total_xp — Poin gamifikasi
  • current_streak — Streak hari
  • longest_streak — Streak terpanjang
